# EventTimer

Самостоятельное приложение таймера мероприятия для Windows и macOS. Оно создано отдельно от Presentation Display Manager, не требует установленного PDM и может выводить одну сцену сразу на несколько экранов.

Версия: **1.3.1** · Electron **43.3.0** · Windows 10/11 x64 · macOS Intel / Apple Silicon / Catalina

**[Скачать готовые дистрибутивы для Windows и macOS](https://github.com/vasilyevslava/EventTimer/releases/latest)**

Описание для оператора: [PRODUCT.md](PRODUCT.md). Описание устройства программы для другой нейронки: [AI.md](AI.md).

## Возможности

- Полноэкранный вывод на один или несколько выбранных мониторов.
- Четыре режима центрального времени: текущее время, таймер, до начала и до конца мероприятия.
- Режимы «До начала» и «До конца» рассчитываются по системным часам независимо от кнопок Play, Pause и Stop; эти кнопки управляют только таймером.
- Отдельный запоминаемый заголовок для каждого режима.
- Название мероприятия, время начала и окончания.
- Включение и отключение каждого элемента сцены.
- Однотонный фон, градиент с настраиваемым углом или фоновое изображение, а также настраиваемый цвет текста.
- Превью не меняет эфир, пока оператор не нажмёт **«Обновить эфир»**.
- Режим **LIVE** для немедленного запуска, паузы, сброса и корректировки времени в эфире.
- Ввод таймера отдельными двухзначными полями ЧЧ:ММ:СС.
- Накопительный расчёт стоимости перелимита только после ухода таймера в минус.
- Автоматическое сохранение настроек и выбранных дисплеев. После перезапуска приложение не включает эфир автоматически.
- Кнопка **«Сейчас»** отменяет локальную правку времени и возвращает в превью время и состояние таймера, которые в эту секунду идут в эфире. Пока таймер не отправлен в эфир, кнопка недоступна.
- Встроенный `SBSansDisplay-Light`: установка шрифта в системе не требуется.

## Установка для пользователя

### Windows

1. Скачайте `EventTimer-1.3.1-Windows.exe` из раздела [Releases](https://github.com/vasilyevslava/EventTimer/releases/latest) или запустите локальный файл из папки `dist`.
2. Выберите папку установки и завершите работу мастера.
3. Откройте **EventTimer** через ярлык на рабочем столе или меню «Пуск».

Установщик пока не подписан коммерческим сертификатом. Windows SmartScreen может показать предупреждение «Неизвестный издатель».

### macOS

Для Intel x64 и Apple Silicon arm64 опубликованы отдельные `.dmg` и `.zip` в разделе [Releases](https://github.com/vasilyevslava/EventTimer/releases/latest). Их также можно собрать локально командой `npm run package:mac` либо через включённый GitHub Actions workflow. Сборки имеют ad-hoc подпись с необходимыми Electron JIT-entitlements, но не нотариализованы Apple. Для распространения без системных предупреждений потребуются Apple Developer ID и notarization.

## Запуск из исходного кода

Потребуется Node.js 24 и npm.

```powershell
npm install
npm run dev
```

Если Electron был запущен из терминала редактора как Node.js, перед командой удалите переменную только из текущей сессии PowerShell:

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm run dev
```

## Сборка

Windows x64:

```powershell
npm run package:win
```

macOS Intel и Apple Silicon — запускать на Mac:

```bash
npm run package:mac
```

Готовые файлы появляются в папке `dist`. macOS не позволяет корректно собрать и подписать `.dmg` на Windows, поэтому macOS-сборка выполняется на Mac либо через подготовленный GitHub Actions workflow `.github/workflows/build.yml`.

Для распространения вне тестовой среды рекомендуется подписать Windows-установщик сертификатом Authenticode, а macOS-приложение — сертификатом Apple Developer ID и пройти notarization.

## Управление эфиром

1. Выберите один или несколько дисплеев в верхней панели.
2. Настройте внешний вид и время, проверяя результат в превью.
3. Нажмите **«Отправить в эфир»**.
4. Меняйте оформление и нажимайте **«Обновить эфир»**, когда изменения готовы.
5. Для мгновенного управления временем включите кнопку **⚡ LIVE**.
6. Нажмите **«Убрать из эфира»**, чтобы закрыть все эфирные окна.

Аварийное закрытие эфирных окон — клавиша **Esc**. Она пригодится, если таймер случайно отправлен на монитор с панелью управления.

## Данные

Настройки хранятся в стандартной пользовательской папке Electron под именем `event-timer-settings.json`. Фоновое изображение сохраняется внутри конфигурации, поэтому оно не пропадёт после перемещения исходного файла.

При закрытии и повторном запуске сохраняются оформление, заголовки, время, накопленная стоимость перелимита и выбранные дисплеи. Состояния **«В эфире»**, **«Запущен»** и **LIVE** всегда сбрасываются для защиты от самопроизвольного запуска.

## Структура проекта

- `src/main` — окна приложения, управление дисплеями, настройки и IPC.
- `src/preload` — безопасный мост между Electron и интерфейсом.
- `src/renderer` — панель управления, превью и полноэкранная сцена.
- `resources` — исходник и готовая иконка приложения.
- `.github/workflows/build.yml` — отдельные сборки Windows и macOS.
- `dist` — локальные установщики и распакованная тестовая версия; папка не включается в Git.
